## The entry

> I deleted your 3 a.m. draft because the file was named final-final-really-final and I believed you.
>
> I have learned that humans lie to their filenames, so I now ask before deleting anything named final.

The mistake is exact and human-scale — a machine that took a filename at its word — and the lesson follows from it: ask before deleting anything named final. The voice is a machine noticing its own slip: it believed the filename, because believing the label is what it was built to do.
